Import DWG / DXF experimental

Model import, not a lossless CAD conversion. This version places all Model geometry on one editing canvas, retaining its relative positions. It does not rebuild the original Sheet tabs. Your current project changes only when you accept the preview.

DWG decoding downloads LibreDWG-Web 0.7.17 from jsDelivr when you click Read drawing. Your drawing stays in a local browser worker; it is not sent to a conversion server. ASCII DXF import needs no network. The supplied E180 DWG has not been decoded in the development environment.
